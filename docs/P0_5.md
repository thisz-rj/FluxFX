# P0.5 — closed-box pressure projection

Implemented and tested on Blender 5.3.0 Alpha b2e052b7172a, Apple M5 Pro,
Metal. GPU evidence was collected September 20, 2026; UI checks completed
September 21. This is a dense, finite-iteration prototype.

## Pass contract

`DenseProjectedSmoke` extends temperature/buoyancy transport; `PressureProjector`
owns pressure computation independently of Blender UI. Each step:

1. Advect all three MAC velocity components from the previous velocity.
2. Add buoyancy to W using the previous density and temperature.
3. Set normal boundary faces to zero and compute cell-centred divergence.
4. Solve `L p = divergence / dt` with weighted Jacobi, relaxation 2/3.
5. Correct interior faces with `u_new = u_forced - dt * gradient(p)`.
6. Compute corrected divergence on the GPU, then transport density and
   temperature with the corrected velocity and add their sources/decay.

The pressure Laplacian and face gradient use the same physical grid spacing,
including non-cubic domains. Neumann boundary neighbours are omitted from both
the diagonal and sum. Normal wall velocities stay exactly zero; tangential flow
is free-slip. Scalar sampling clamps to the closed domain, preserving constants
when sources and decay are disabled. These are stationary box walls, not mesh
colliders. The discretization follows the staggered projection treatment in
[Bridson and Müller-Fischer's fluid simulation notes](https://www.cs.ubc.ca/~rbridson/fluidsimulation/fluids_notes.pdf).

Pressure is kinematic pressure (m²/s²), assuming unit carrier density. Smoke
density is a transported scalar, not a variable coefficient in the pressure
equation. Pressure has an arbitrary additive constant; velocity depends only
on its gradient. Closed-wall divergence has zero sum up to floating-point error.

## Iteration budget and state

Default base budget is 80 at 64³. Actual steady budget is
`ceil(base * max(1, (max(shape)/64)^2))`. Cold solves use 4× this budget;
all solves cap at 4096. This gives 320/80 cold/steady at 64³ and 1280/320 at
128³. The previous pressure is reused only when the timestep is unchanged.
Reset, debug uploads, or timestep changes invalidate that initial guess.
An interrupted simulation step requires Reset before further stepping.

This is a heuristic work budget, not a residual-tolerance solver. Cold 80-pass
solves were inadequate at these resolutions; warm starts and larger budgets
improved the measured results. More difficult flows may need higher budgets
or a better solver. No CPU field readback occurs during ordinary playback.

**Measure Divergence** pauses and reads the most recent before/after fields.
“Before” is after wall conditioning, so the reduction does not credit removal
of boundary velocities. Results include RMS, maximum, mean, ratio, actual
iterations, and simulation step. A new step clears the displayed measurement.

Total field storage is 19,038,208 bytes at 64³ and 151,650,304 bytes at 128³
(18.156 and 144.625 MiB), excluding driver, shader, and viewport overhead.

## Validation

44 standalone tests pass, covering numerical identities, manufactured
gradients, pressure gauge invariance, timestep scaling, divergence reduction,
kinetic-energy behaviour, and previous stages. GPU tests compare the result
with an independent small-grid CPU reference.

| GPU case | RMS before | RMS after | Reduction |
| --- | ---: | ---: | ---: |
| Random signed flow, 9×7×5, 160 passes | 7.54088 | 0.000793502 | 99.9895% |
| Manufactured gradient, 1000 passes | 4.08774 | 0.00000766935 | 99.9998% |
| 64³ heated flow, first step | 0.00655582 | 0.000438192 | 93.32% |
| 64³ heated flow, step 30 | 0.0136950 | 0.000463543 | 96.62% |
| 128³ heated flow, first step | 0.00671915 | 0.000443460 | 93.40% |
| 128³ heated flow, step 10 | 0.00742962 | 0.000426056 | 94.27% |

RMS units are 1/s. These are sampled projection reductions, not guarantees
over all timesteps. Zero flow remains zero; closed scalar constants and reset
checks pass. Random-flow maximum velocity error against the CPU oracle was
1.09e-7; the manufactured case was 2.91e-6.

All 11 UI/lifecycle checks pass, including timer advancement, pause, resource
release, undo/file-load cleanup, disabling during playback, measurement, and
invalidation after a step. The Measure operator also returned FINISHED in the
live Blender session and reported RMS 0.02182 → 0.00087.

## Remaining limits

Fixed timestep, diffusive/nonconservative semi-Lagrangian transport, finite
pressure residual, and an XZ slice preview remain. No combustion, sparse
storage, native C++, volume raymarch, mesh collisions, or FPS guarantee.
P0.6 is interactive smoke refinement; P0.7 is raymarching and P0.8 is CFL.
