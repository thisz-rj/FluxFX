# P0.7 — GPU volume preview

Tested September 21, 2026 on Blender 5.3.0 Alpha b2e052b7172a, Apple M5 Pro,
Metal. The default preview integrates the complete 3D density field in an
orthographic inset. Orbiting Blender's viewport rotates the viewing direction.
It uses the same GPU textures as the solver, without CPU readback during display.

## Controls

**View → 3D volume** selects raymarching; **XZ slice** retains the diagnostic
cross section. Density and signed temperature views both work. **Ray samples**
selects 64, 128, or 256 samples per intersecting ray. **Opacity scale** controls
extinction; it changes appearance, not simulation. Display changes preserve all
simulation fields. Increasing sample count can improve fine detail at a GPU cost.

The inset frames the whole fixed 1 m cube and follows viewport rotation only.
Pan, zoom, perspective, and scene camera position do not change its framing.
The underlying volume is three-dimensional even though output is an inset image.

## Rendering

The fragment shader intersects each orthographic ray with the unit box using a
slab test with explicit handling of parallel rays. It samples interval midpoints
and accumulates emission/absorption front-to-back, using
`alpha = 1 - exp(-opacity_scale * density * step_length)`. Sample spacing is part
of opacity, so a constant field has the same optical thickness at every quality
setting. Marching stops early below 0.001 remaining transmittance.

Manual clamped trilinear sampling keeps compute textures in their existing
nearest-filtered mode. Density is nonnegative for opacity; temperature uses
absolute excess divided by 100 K, with orange/blue sign colour. This temperature
view is diagnostic, not blackbody emission or combustion.

`blender/preview.py` owns the graphics shader/batch. The numerical backend is
unchanged. Blend/depth state is restored after drawing. Shutdown releases both
slice and volume preview objects. The volume shader is packaged with the add-on.

## Validation

47 existing standalone tests pass. Eighteen GPU render cases pass at 64, 128,
and 256 samples, checking empty fields, constant fields from front/side/diagonal,
a linear X field (interpolation), and signed cold temperature. Centre framebuffer
pixels match analytic absorption within 2e-5; off-box rays match the background
within 2e-6. Tests use an RGBA32F offscreen target and actual Metal rendering.
All 12 UI/lifecycle checks pass with both preview shaders compiled and resource
release verified. The density volume was visually inspected in Blender.

## Limits

This is an unlit emission/absorption preview with fixed smoke colour. No scene
geometry occlusion, volume shadows, scattering, lighting, or EEVEE/Cycles output.
No performance guarantee: each pixel takes up to 256 samples with eight texture
fetches each. Rendering uses no additional simulation-sized volume textures.
Fixed timestep and approximate pressure projection remain. Next is P0.8,
adaptive CFL timestepping.
